## Глава 1. Знакомство с python

### 1\) ввод-вывод данных, переменные
- Для вывода данных на экран используется команда `print()`<br>
- Для ввода данных с клавиатуры используется команда `input()`<br>
- Переменные:
Любая переменная имеет имя и значение.<br>
```
variable_name = input()
print('Вы ввели текст:', variable_name)
```
