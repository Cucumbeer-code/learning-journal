### 2\) Параметры sep и end, PEP8

- У команды `print()` есть параметр, который отвечает за разделение аргументов при выводе. Этот параметр называется `sep` (separator – разделитель). По умолчанию этот параметр равен символу пробела ` `.
- у команды `print()` есть параметр `end`, определяющий, что нужно добавить в конец вывода. По умолчанию параметр end равен символу перевода строки (`\n`).

Приведённый ниже код:

`print('a', 'b', 'c', sep='*', end='finish')`

                  
выводит:

`a*b*cfinish`

### 3\) Работа с целыми числами

- Целые числа: 
    ```
    num1 = 7     #num1 - это число
    ```
- Основные операции с числами
    ```
    + | сложение
    - | вычитание
    * | умножение
    **| возведение в степень
    / | деление
    //| деление нацело
    % | отсаток от деления
    ```
- Преобразование строки к целому числу
    Для того чтобы преобразовать строку к целому числу, мы используем команду int().
    Для того чтобы преобразовать целое число в строку, мы используем команду str().
